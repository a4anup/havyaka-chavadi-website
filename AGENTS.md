# Havyaka Chavadi website agent rules

- Maintain a static, deployable bilingual promotional site.
- Every visible UI string belongs in `config/locales.json`, with matching keys for `en` and `kn`.
- Use only supplied artwork in `assets/` unless the user requests additional imagery.
- Preserve original artwork and Kannada text in image files.
- Shared brand colors are CSS variables in `css/styles.css`.
- Maintain working English/Kannada and light/dark/auto toggles.
- No fake download buttons, waitlist forms, unverifiable claims, or member-data collection.
- Keep accessible, responsive design and avoid unnecessary dependencies.
